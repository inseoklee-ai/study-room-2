🎭 이 장이 푸는 문제 — 스타일이 제멋대로

파운데이션 모델(foundational model)은 거대한 데이터셋으로 학습되어 아주 다양한 콘텐츠를 만든다. 그런데 그 스타일은 두 가지에 좌우된다.

🧩 프롬프트로 하면 왜 안 되는가

톤·어휘·읽기 수준·서식 — 이 모든 측면을 프롬프트 엔지니어링으로 제어해 볼 수는 있다. 하지만 그런 접근은 극도로 취약하다(brittle).

1결과가 모델마다 다르다
2결과가 시도할 때마다 또 다르다 — 1장의 비결정성
3지시를 잘 따르는 큰 모델일수록 비싸다
"친근한 말투로 써 줘"는
지켜 주면 좋고 아니면 마는 부탁이다
이 장의 다섯 패턴은 이 문제에 대해 더 정교하고 견고한 해법을 제공합니다. 필요에 맞는 것을 고르거나 여러 개를 조합하면 됩니다.
중요한 건 "프롬프트가 나쁘다"가 아닙니다. 좋은 모델은 대체로 잘 지켜요. 문제는 보장이 없다는 것, 그리고 그 보장 없음의 비용을 다운스트림 전체가 나눠 낸다는 것입니다.

패턴 1 로짓 마스킹 — 요약

❌ 문제

브랜딩·정확성·컴플라이언스·스타일북 때문에 텍스트가 특정 규칙을 따라야 한다.

✅ 해법

샘플링 단계에서 생성을 가로채 규칙에 안 맞는 연속의 확률을 0으로 만든다.

🎰 안티패턴 — "될 때까지 다시 해 보기"는 성공률이 아주 높을 때만 쓸 만합니다. 성공률 30%면 최악(99분위) 13회, 평균 지연 +230%.
🔒 제약 — 로짓 접근이 필요합니다. 2025년 6월 기준 Anthropic Claude는 제공하지 않고, 통신 비용 때문에 로컬 호스팅 모델에만 적용 가능한 경우가 많습니다.

상세 → 패턴 1 덱

패턴 1은 표현력이 가장 크지만 쓸 수 있는 모델이 가장 적습니다. 이 트레이드오프가 2장 내내 반복됩니다.

패턴 2 문법 — 요약

❌ 문제

다운스트림 처리를 위해 텍스트가 특정 형식이나 데이터 스키마를 따라야 한다.

✅ 해법

규칙을 형식 문법(BNF)이나 스키마로 명시하면 모델 프레임워크가 토큰 생성을 제약한다.

LLM 호출을 소비하는 모든 쪽이
지시 불이행에 대비해야 한다
💡 세 가지 방법 — ① 스키마·dataclass(여기서 시작) ② JSON 모드 ③ BNF 문법. 실무 대부분이 ①에서 끝납니다.

상세 → 패턴 2 덱

패턴 1과 하는 일은 같습니다. 모델 서버가 대신 해준다는 것만 달라요. 그래서 형식 문제라면 무조건 이쪽이 낫습니다.

패턴 3 스타일 전이 — 요약

❌ 문제

규칙으로 표현하기 어렵지만 변환 예시로는 보여 줄 수 있는 톤·문체를 모방해야 한다.

✅ 해법

퓨샷 러닝 또는 모델 파인튜닝으로 변환하는 법을 가르친다.

🎯 성립 조건 셋 — ① 가용한 콘텐츠가 있다 ② 스타일이 미묘해 규칙으로 못 쓴다("보면 안다") ③ 전문가의 변환 예시가 있다
퓨샷파인튜닝
예시 개수1~10개100~수천 개

수정즉시재학습

상세 → 패턴 3 덱

텍스트만이 아니라 이미지에도 적용됩니다. 저자들은 프리드리히의 「안개 바다 위의 방랑자」 스타일로 스타워즈 포스터를 만드는 예를 보여줍니다.

패턴 4 역중립화 — 요약

❌ 문제

특정 스타일로 콘텐츠를 만들어야 하는데 변환 전·후 쌍이 없다. 내 스타일의 결과물만 있다.

✅ 해법

가진 결과물을 중립화한 뒤 화살표를 뒤집어 학습 데이터로 쓴다.

① 내 이메일  →[AI에게 밋밋하게]→  중립 버전
② 화살표를 뒤집는다:  중립 버전  →  내 이메일   ← 짝 완성
③ 이 짝으로 파인튜닝
🔄 추론은 두 단계 — 파운데이션 모델이 중립 형태를 만들고, 파인튜닝 모델이 원하는 스타일로 변환합니다. "중립"이 다리 역할을 해요.

상세 → 패턴 4 덱

기계번역의 역번역(back translation)과 같은 발상입니다. 결과물은 있는데 그걸 만들어낸 입력이 없을 때 쓰는 패턴이에요.

패턴 5 콘텐츠 최적화 — 요약

❌ 문제

어떤 요인이 중요한지 모르는 채로 최적 스타일을 알아내야 한다. 가설이 없으면 A/B 테스트가 불가능하다.

✅ 해법

콘텐츠 쌍을 만들어 비교하고, 그 선호 데이터셋으로 선호 튜닝(DPO)한다.

프롬프트를 바꾸지 않는다
대신 LLM을 바꾼다
💡 실측 — 예시 100개, L4 GPU 한 장에서 학습 약 3분. 5억 파라미터 Qwen2가 쓸 만한 광고를 쓰게 됐습니다.
⚠️ 평가자가 곧 천장입니다. 저자도 "평가 방법이 훌륭하다고 여길 콘텐츠를 만들도록 모델을 해킹한다"고 인정합니다 — 시험에 맞춰 가르치는 것.
